# Budget Router Lite privacy policy

Budget Router Lite is a set of markdown files for Claude Code: skills (commands) and helper agents. It contains no code, no hooks and no options. It makes no network requests, has no server or account, and has no analytics or telemetry. It collects no data and stores none.

Contact: open an issue at https://github.com/ValhalaStudio/budget-router-kit/issues

## What it handles

Nothing on its own. When you run one of its commands, the text you type is handled by Claude Code and the model you chose, under Anthropic's terms, exactly as if you had typed it without the plugin. The plugin itself never receives, copies or keeps it.

- `:handoff` asks Claude to write a file you named, using Claude's own file tool and permission prompts.
- The helper agents act through Claude's normal tools, with the permissions you have set.
- `:tips` reads the cheatsheet bundled in this plugin.

## What it stores, and for how long

Nothing. Uninstalling the plugin removes it completely. A handoff file you asked for stays until you delete it.

## Children

The plugin is a developer tool and is not intended for people under 18.
